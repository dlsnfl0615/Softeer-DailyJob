# 오늘 한 것
## @PathVariable
```java
@RestController
@RequestMapping("/users")
public class UserController {

    @GetMapping("/{userId}")
    public String getUser(@PathVariable("userId") Long userId) {
        return "요청한 유저 ID: " + userId;
    }
}
```
/users/{userId} 경로의 {userId} 부분(중괄호로 감싼 부분)이 실제 요청 시 URL에 들어오는 값(예: /users/42)과 매칭되어 userId 파라미터에 42가 들어감
매개변수 변수명을 경로 변수명과 일치시키면 @PathVariable에 이름 안 써도 됨
