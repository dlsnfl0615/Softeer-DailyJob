## 오늘 한 것
### api 호출 응답 받을 때 필요없는 값 무시하기
```java
@JsonIgnoreProperties(ignoreUnknown = true) // 정의하지 않은 메타 데이터나 다른 필드는 무시
@JsonNaming(PropertyNamingStrategies.SnakeCaseStrategy.class)
public record CoordinatesResponseDto(
        List<Document> documents
) {
    @JsonIgnoreProperties(ignoreUnknown = true)
    @JsonNaming(PropertyNamingStrategies.SnakeCaseStrategy.class)
    public record Document(
            RoadAddress roadAddress
    ) {
    }

    @JsonIgnoreProperties(ignoreUnknown = true)
    @JsonNaming(PropertyNamingStrategies.SnakeCaseStrategy.class)
    public record RoadAddress(
            String addressName,
            String region1depthName,
            String region2depthName,
            String region3depthName,
            String roadName,
            String mainBuildingNo,
            String subBuildingNo,
            String buildingName,
            String zoneNo,
            String x, // 경도
            String y  // 위도
    ) {
    }
}
```
- `@JsonIgnoreProperties(ignoreUnknown = true)`: 정의하지 않은 다른 필드는 무시.
  - 이거 안 쓰면 api의 응답 양식 그대로 dto에 다 정의해줘야 함
