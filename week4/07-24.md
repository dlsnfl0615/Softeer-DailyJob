## JPA
### 기본 예제
```java
@Entity
@Table(name = "products")
public class Product {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private long id;

    @Column(nullable = false)
    private String name;

    private int price;

    protected Product() {}

    public Product(String name, int price) {
        this.name = name;
        this.price = price;
    }
}
```
- @Entity: 클래스가 JPA 엔티티임을 선언
- @Table(name = "products"): 엔티티가 매핑될 실제 테이블명 지정
  - 해당 어노테이션 생략하면 테이블명이랑 매칭되는데 클래스명과 테이블명 다르게 하고 싶으면 사용
- @Id: 해당 필드가 기본키임
- @GeneratedValue(strategy = GenerationType.IDENTITY): 기본키 생성 전략
  1. IDENTITY: DB의 auto-increment에 위임 (MySQL 등에서 흔히 사용, 단 배치 insert 최적화가 안 됨)
  2. SEQUENCE: DB 시퀀스 오브젝트 사용 (Oracle, PostgreSQL에서 선호, 성능상 유리)
  3. TABLE: 키 생성 전용 테이블 사용 (모든 DB 호환되지만 성능 낮음, 거의 안 씀)
  4. AUTO: JPA 구현체가 DB 방언에 맞춰 자동 선택
- @Column(nullable = false): column의 세부 속성 지정
  - 자바 타입을 DB 타입으로 자동 변환해주는 경우

    | 자바 타입 | 매핑되는 DB 타입 (H2/MySQL 기준) |
    |---|---|
    | `int` / `Integer` | `INTEGER` |
    | `long` / `Long` | `BIGINT` |
    | `String` | `VARCHAR(255)` ← 기본 길이 255 |
    | `boolean` / `Boolean` | `BOOLEAN` (MySQL은 `TINYINT(1)`) |
    | `BigDecimal` | `DECIMAL(19,2)` (기본 precision/scale) |
    | `LocalDate` | `DATE` |
    | `LocalDateTime` | `TIMESTAMP` |
    | `byte[]` | `VARBINARY` / `BLOB` |

  - 속성 자세히 설명하고 싶으면
    ```java
    @Column(
      name = "product_name",
      nullable = false,
      unique = false,
      length = 100,
      precision = 10,
      scale = 2,
      insertable = true,
      updatable = true,
      columnDefinition = ""
    )
    private String name;
    ```
    - name: 매핑될 실제 컬럼명. 안 쓰면 필드명 기준(카멜케이스→스네이크케이스 자동 변환, productName → product_name).
    - nullable: false면 DDL에 NOT NULL 추가. (뒤에서 자세히)
    - unique: true면 단일 컬럼 UNIQUE 제약 추가. 복합 유니크는 @Table(uniqueConstraints = ...)로 따로 지정해야 함.
    - length: String이 VARCHAR로 매핑될 때 길이. 기본값 255.
    - precision / scale: BigDecimal 등에서 전체 자릿수/소수점 자릿수. precision=10, scale=2면 DECIMAL(10,2) (최대 12345678.90).
    - insertable / updatable: false로 하면 INSERT/UPDATE 쿼리에서 해당 컬럼을 아예 빼버림. DB 트리거로 관리되는 컬럼이나, 읽기 전용 계산 컬럼에 씀.
    - columnDefinition: Hibernate의 타입 매핑을 무시하고 원하는 DDL을 직접 씀. 예: @Column(columnDefinition = "TEXT")로 255자 제한을 없애고 긴 텍스트 저장.

```java
public interface ProductRepository extends JpaRepository<Product, Long> {
    List<Product> findProductsByName(String keyword);
}

---

@Service
@Transactional(readOnly = true)
public class ProductService {

    private final ProductRepository productRepository;

    public ProductService(ProductRepository productRepository) {
        this.productRepository = productRepository;
    }

    @Transactional
    public Product create(String name, int price) {
        Product product = new Product(name, price);
        return productRepository.save(product);
    }

    public List<Product> findAll() {
        return productRepository.findAll();
    }

    public Product findById(Long id) {
        return productRepository.findById(id)
                .orElseThrow(() -> new IllegalArgumentException("존재하지 않는 상품입니다. id=" + id));
    }

    @Transactional
    public Product updatePrice(Long id, int price) {
        Product product = findById(id);
        product.updatePrice(price);
        return product; // 변경 감지(dirty checking)로 별도 save 불필요
    }
}
```
- JpaRepository<Product, Long>: Product는 엔티티 타입, Long은 pk 타입
  - ave(), findById(), findAll(), delete() 등 기본 CRUD가 구현체 없이 바로 제공됨
- findByNameContaining(String keyword): 메서드 이름으로 쿼리 생성
  - findBy + 필드명 + 조건 키워드(Containing, GreaterThan, OrderBy 등) 조합으로 Spring Data JPA가 자동으로 JPQL을 만들어줌

```java
@RestController
@RequestMapping("/api/products")
public class ProductController {

    private final ProductService productService;

    public ProductController(ProductService productService) {
        this.productService = productService;
    }

    @PostMapping
    public Product create(@RequestBody CreateRequest request) {
        return productService.create(request.name(), request.price());
    }

    @GetMapping
    public List<Product> findAll() {
        return productService.findAll();
    }

    @GetMapping("/{id}")
    public Product findById(@PathVariable Long id) {
        return productService.findById(id);
    }

    @PatchMapping("/{id}/price")
    public Product updatePrice(@PathVariable Long id, @RequestBody UpdatePriceRequest request) {
        return productService.updatePrice(id, request.price());
    }

    // Java record를 DTO로 사용 (Spring Boot 4.x에서도 그대로 지원)
    public record CreateRequest(String name, int price) {}
    public record UpdatePriceRequest(int price) {}
}
```
