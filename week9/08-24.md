# 오늘 한 일
## CloudFront 페이지 없는데 접근하는 경우
- 사용자가 https://yourapp.com/mypage로 접속 시, S3는 실제로 mypage라는 파일이나 폴더가 있는지 탐색
- /mypage는 React Router가 브라우저 안에서(JS로) 처리하는 가상의 경로일 뿐, 실제 서버/스토리지에는 없는 경로
- S3는 "해당 파일 없음" → 404(또는 접근 정책에 따라 403) 반환

### index.html로 리다이렉트
React 앱은 처음 로드 시 index.html 하나만 받고, 그 안의 JS(React Router)가 URL을 보고 어떤 화면을 그릴지 결정하는 구조.
- /로 최초 진입 시: index.html 로드 → React Router가 홈 화면 렌더링 → 정상
- /mypage로 최초 진입(새로고침 포함) 시: index.html이 필요하나 S3는 mypage라는 파일을 탐색하다 미발견 → 404
- 따라서 "404/403 발생 시 index.html로 대체 반환"하도록 CloudFront에 설정 필요 — 이래야 index.html 로드 후 그 안의 React Router가 /mypage 경로를 인식해 마이페이지 렌더링
